_main:
  ┌─ mov  x0, #1    ─┐
  │  adr  x1, msg    │  인자 세팅
  │  mov  x2, #12    │  write(1, msg, 12)
  │  mov  x16, #4   ─┘
  └─ svc  #0x80  ────── OS: 화면에 출력!

  ┌─ mov  x0, #0    ─┐
  │  mov  x16, #1   ─┘  인자 세팅
  └─ svc  #0x80  ────── OS: 프로그램 종료!

## 참고
파일 디스크립터 번호 약속:
- 0 = stdin  (키보드 입력)
- 1 = stdout (터미널 출력)  ← 지금 이것
- 2 = stderr (에러 출력)


파일 디스크립터 (fd)        종료 코드 (exit code)
─────────────────────       ──────────────────────
0 = stdin                   0 = 성공
1 = stdout                  1 = 일반 오류
2 = stderr                  2 = 잘못된 사용
                            127 = 명령어 못 찾음

write() 가 쓰는 개념         exit() 가 쓰는 개념
둘이 아무 관련 없음
